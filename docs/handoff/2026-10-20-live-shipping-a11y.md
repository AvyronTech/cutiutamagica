# Handoff — corecții descoperite după prima publicare, 20 octombrie 2026

- Ramură: `codex/live-shipping-a11y`, pornită din commitul de integrare `3216943` al ramurii `codex/cutiuta-cloudflare-final`.
- Auditul live pe mobil a confirmat scoruri Lighthouse 100 pentru accesibilitate, Best Practices și SEO pe catalog și produs. Pe home, imaginile din caruselul cu produse disponibile aveau etichete accesibile care ignorau textele vizibile din ecusoane; `src/components/site/RotatingSpotlight.tsx` lasă acum numele linkului să includă conținutul vizibil.
- Testul Easybox pe mobil a confirmat că lista oficială încarcă 80 de puncte pentru București, punctul selectat rămâne în checkout, iar butonul „Alege punctul de ridicare” închide dialogul. [Captura mobilă](../release-evidence/2026-10-20/easybox-mobile.webp) arată harta, lista și butonul fixat sub hartă. La cotație, lockerul oficial trimite `city=Sectorul 1`, `county=Bucuresti`, `postalCode=010235`; rezolvarea localității răspundea greșit „Verifică localitatea”. Conform [documentației SmartShip](https://smartship.ro/api-docs), București este localitatea, iar sectorul se trimite separat. `src/server/integrations/smartship.ts` caută acum localitatea București pentru un sector din județul București; sectorul numeric rămâne separat, din codul poștal. Regula acoperă și emiterea AWB, care folosește aceeași funcție.
- `src/server/growth.test.ts` adaugă regresia pentru formele „Sectorul 1” și „Sector 2”. `src/components/site/CheckoutDelivery.tsx` și `src/routes/comanda.tsx` explică faptul că tariful se calculează după completarea datelor când punctul este deja ales. Totalul final rămâne afișat înainte de plată.
- Migrații D1 noi: niciuna. Nu se schimbă disponibilitatea, prețurile, datele de client, furnizorii sau secretele.
- Verificări locale trecute: `npm run typecheck`, `npm test` (56 fișiere, 301 teste), `npm run lint`, `npm run build`, `npm run cf:deploy:dry` și `git diff --check`. După publicare trebuie repetate verificarea live a tarifului Easybox și auditul paginii principale pe mobil. Capturile desktop/mobil ale paginilor se află în `docs/release-evidence/2026-10-20/`.
