# Instrucțiuni Lovable

Cutiuța Magică este o aplicație comercială Cloudflare, nu un proiect Supabase. Citește `AGENTS.md` și `docs/AGENT_HANDOFF.md` înainte de modificări. Livrează schimbările vizuale printr-o ramură pornită din `codex/cutiuta-cloudflare-final` și un pull request către aceeași ramură. Nu șterge Worker API, migrațiile D1, R2, KV, checkoutul sau dashboardul.
